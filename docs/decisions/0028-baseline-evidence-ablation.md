# 0028. baseline은 같은 모델로 evidence를 줄 때와 안 줄 때를 비교한다

- 날짜: 2026-11-09
- 상태: 채택
- 결정자: 사용자
- AI 관여: 선택지 조사·추천 (Claude 추천: 같은 모델 × evidence 있음/없음, 채택 여부: 예)
- 관련 결정 ID: D24

## 맥락
`compare`와 사실 추출을 실제 데이터로 보여 주려면 실행 결과 두 개가 필요하다. 두 실행의 차이가 무엇 때문인지 분명해야 비교 결과를 해석할 수 있다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| 같은 모델 × evidence 있음/없음 | 변수가 하나라 원인이 분명함, 차이가 클 가능성이 높음(BIRD 논문도 evidence 효과를 보고), 오답이 많아 사실 설계 재료가 풍부 | 연구의 프롬프트 반복 실험과는 조금 다름 |
| 같은 모델 × 프롬프트 2종 | 연구하던 방식과 가장 비슷함 | 차이가 작아 비교가 덜 선명할 수 있음 |
| 모델 2개 × 같은 프롬프트 | 모델 비교라는 흔한 질문 | 비용이 모델에 따라 커짐 |

## 결정
`examples/baseline`은 같은 모델, 같은 프롬프트 틀로 두 번 예측한다. 한 번은 BIRD의 `evidence`를 프롬프트에 넣고, 한 번은 넣지 않는다.

## 이유
추천안(같은 모델로 evidence 있음·없음 두 번 예측)을 채택했다.

## 결과
- 두 예측 파일과 실행 파일을 `examples/results/`에 커밋해, API 키 없이도 `eval`·`report`·`compare`를 재현할 수 있게 한다.
- 모델은 D33에서 정한다.
