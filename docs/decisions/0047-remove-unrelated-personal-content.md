# 0047. 공개 전에 프로젝트와 무관한 개인 정보를 현재 파일에서 지운다

- 날짜: 2026-11-15
- 상태: 채택
- 결정자: 사용자
- AI 관여: 선택지 조사·추천 (Claude 추천: 현재 파일에서 개인 일정·타사 내용만 지움, 채택 여부: 예, 범위는 사용자가 넓힘)
- 관련 결정 ID: D43

## 맥락
저장소를 공개하면 계획서(`docs/PLAN.md`), 개발 기록, ADR을 누구나 읽는다. 공개 전 점검(2026-11-15)에서 프로젝트와 관계없는 개인 정보(개인 일정, 학교 등)가 발견됐다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| 그대로 공개 | 작업 없음, 과정을 숨김없이 보여 줌 | 무관한 개인 정보가 그대로 보임 |
| 현재 파일에서만 지움 | 저장소 화면과 문서에서는 안 보임 | 이전 커밋 기록에는 남음 |
| 커밋 기록까지 지움(히스토리 재작성) | 완전히 사라짐 | "이미 push한 커밋은 고치지 않는다"(AGENTS.md) 위반, 모든 커밋 SHA와 링크가 바뀜 |

## 결정
현재 파일에서 text2sql-eval 프로젝트와 무관한 내용을 모두 지운다. 학교와 학년도 지운다. 커밋 기록은 고치지 않는다.

## 이유
> "학교, 학년 이런 것도 다 지워줘. 그냥 이 text2sql-eval 프로젝트와 무관한건 싹다 지우고 싶어."

## 결과
- Claude가 후보를 "확실히 무관한 것"과 "애매한 것"으로 나눠 제시하고, 사용자가 확인한 범위만 지운다.
- 이전 커밋에는 지운 내용이 남는다. 커밋 기록을 열면 볼 수 있다.
