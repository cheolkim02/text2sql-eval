# 0002. 프로젝트 이름을 `text2sql-eval`로 한다

- 날짜: 2026-11-03 (기록: 2026-11-07)
- 상태: 채택
- 결정자: 사용자
- AI 관여: PyPI 이름 사용 가능 여부 확인 (2026-11-04)
- 관련 결정 ID: D1

## 맥락
저장소, 배포 패키지, import 이름, CLI 명령어 이름을 정해야 했다. 계획서 초판에서는 npm 패키지를 전제로 이름을 정했고, 2026-11-04 언어를 Python으로 바꾸면서(0003) PyPI 기준으로 다시 확인했다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| `text2sql-eval` | 무엇을 하는 도구인지 바로 드러남, 연구 분야에서 흔히 쓰는 용어 | 일반적인 이름이라 검색에서 묻힐 수 있음 |
| `nl2sql-eval` | 같은 뜻 | 분야에서 text-to-SQL이 더 흔한 표현 |

## 결정
배포 이름과 CLI 명령어는 `text2sql-eval`, import 이름은 `text2sql_eval`로 한다.

## 이유
계획서 초판(2026-11-03)에서 사용자가 정했다. 2026-11-04 PyPI에서 `text2sql-eval`과 `text2sql_eval` 모두 등록되지 않은 것을 확인했다(API 응답 404).

## 결과
- 실제로 PyPI에 배포하기 전까지는 이름이 선점될 수 있다. 배포는 선택 범위이므로, 선점되면 이 결정을 다시 본다.
