# 0052. syrupy를 개발 의존성에서 뺀다

- 날짜: 2026-11-20
- 상태: 채택
- 결정자: 사용자
- AI 관여: ponytail 점검(0049)에서 쓰이지 않는 의존성을 찾고 선택지 추천 (Claude 추천: 의존성과 문서에서 뺌, 채택 여부: 예)
- 관련 결정 ID: D48

## 맥락
0014에서 스냅샷 테스트 도구로 syrupy를 골랐지만, 테스트에서 한 번도 쓰지 않았다(저장소 전체 검색으로 확인). 커밋된 `examples/results/report.html`을 다시 만든 것과 비교하는 테스트(`tests/test_results.py`)가 스냅샷 역할을 이미 한다. 그런데 `AGENTS.md`와 `CONTRIBUTING.md`는 syrupy 스냅샷을 쓴다고 적고 있어, 문서와 실제가 어긋났다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| 의존성과 문서에서 뺌 | 문서와 실제가 맞고, 설치할 패키지가 하나 줄어듦 | 스냅샷 테스트가 필요해지면 다시 넣어야 함 |
| 남기고 실제로 씀(예: CLI 출력 스냅샷) | 문서가 약속한 대로 됨 | 지킬 테스트가 늘고, 갱신마다 사용자 승인이 필요함 |
| 남기고 문서만 "필요할 때 쓴다"로 고침 | 바꿀 것이 가장 적음 | 쓰지 않는 패키지가 계속 설치됨 |

## 결정
syrupy를 `pyproject.toml`의 개발 의존성과 `uv.lock`에서 빼고, `AGENTS.md`와 `CONTRIBUTING.md`의 syrupy 설명을 지운다. 0014의 pytest와 Hypothesis는 그대로다.

## 이유
추천안(의존성과 문서에서 뺌)을 채택했다. 쓰지 않는 것은 지운다는 원칙(0050의 ponytail)에 맞고, 커밋된 리포트를 비교하는 테스트가 이미 같은 일을 한다.

## 결과
- 스냅샷 테스트가 필요해지면 새 결정으로 다시 넣는다.
- 0014의 상태를 "일부 대체됨(0052)"로 바꾼다. PLAN 결정 표의 D12 행은 그때의 결정이라 그대로 둔다.
