# 0011. 린트와 포맷은 Ruff 하나로 한다

- 날짜: 2026-11-07
- 상태: 채택
- 결정자: 사용자
- AI 관여: 선택지 조사·추천 (Claude 추천: Ruff 하나, 채택 여부: 예). 사용자가 도구를 잘 모른다고 밝혀 추천을 따른 결정이다.
- 관련 결정 ID: D10

## 맥락
코드 스타일 검사(린트)와 자동 정렬(포맷)을 어떤 도구로 할지 정해야 했다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| Ruff 하나 (lint + format) | Flake8·isort·Black 등을 대체, 설정이 `pyproject.toml` 하나에 모임, 빠름 | 규칙 세트를 직접 골라야 함 |
| flake8 + black + isort | 오래 검증된 조합 | 도구 3개, 설정이 흩어짐 |

## 결정
Ruff로 린트(`ruff check`)와 포맷(`ruff format`)을 모두 한다.

## 이유
추천안(Ruff 하나로 린트와 포맷)을 채택했다.

보충: 사용자는 도구를 잘 모른다고 밝혔다. 이 결정은 Claude의 추천을 따른 것이고, Ruff가 무엇을 검사하는지와 고른 규칙 세트의 이유를 `/explain`으로 학습해야 한다.

## 결과
- 켤 규칙 세트는 별도 결정으로 정한다(D28).
- CI에서 `ruff check`와 `ruff format --check`를 돌린다.
