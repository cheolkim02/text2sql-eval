# 0022. EX 판정은 BIRD 공식과 똑같은 집합 비교 하나만 쓴다

- 날짜: 2026-11-08
- 상태: 채택
- 결정자: 사용자
- AI 관여: BIRD 공식 평가 코드 확인과 추천 (Claude 추천: 공식과 똑같은 집합 비교 하나만, 채택 여부: 예)
- 관련 결정 ID: D16

## 맥락
예측 결과와 정답 결과가 "같다"를 정하는 규칙이 EX 점수를 결정한다. BIRD 공식 평가 코드(0021의 두 판)는 `set(predicted_res) == set(ground_truth_res)`로 판정한다.
- 행 순서와 중복 행은 무시한다.
- 한 행 안의 컬럼 순서는 따진다.
- 컬럼 이름은 보지 않는다.
- 값은 Python의 같음으로 비교한다. `1 == 1.0`은 같고, 실수는 정확히 같아야 한다.
- 예외가 나면(실행 실패, 시간 초과) 0점이다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| 공식과 똑같은 집합 비교 하나만 | 논문의 BIRD 점수와 바로 비교 가능, 완료 기준(공식 스크립트와 EX 일치)을 지킴 | 공식 규칙의 약점(순서·중복 무시)을 그대로 가짐 |
| 공식 + 엄격 모드(순서, 중복, 실수 오차) | 더 엄밀한 점수도 볼 수 있음 | 규칙 두 벌, 어느 점수를 믿을지 혼란, 일정 부담 |
| 엄격 모드만 | 가장 엄밀함 | 공식 점수와 비교할 수 없음 |

## 결정
판정 규칙은 공식과 똑같은 집합 비교 하나만 둔다. 예측이나 정답 쿼리가 실패(`error`, `timeout`, `row_limit`)하면 정답이 아니다. 공식 규칙이 놓치는 문제는 판정을 바꾸지 않고 플래그와 사실로 드러낸다.

## 이유
> "공식과 똑같은 집합 비교 하나만"

## 결과
- CLI의 `--mode <bird|strict>` 옵션은 만들지 않는다. 엄격 모드는 로드맵에 둔다.
- 공식 비교 함수와 우리 판정이 항상 같은 답을 내는지 속성 기반 테스트로 지킨다.
- 공식과 결과가 달라질 수 있는 경우는 0021의 두 가지(시간 제한을 재는 단위, 쓰기 쿼리)뿐이어야 한다.
