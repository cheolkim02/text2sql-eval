# 0040. CSV 셀이 수식 문자로 시작하면 앞에 `'`를 붙인다

- 날짜: 2026-11-11
- 상태: 채택
- 결정자: 사용자
- AI 관여: 선택지 조사·추천 (Claude 추천: 위험한 첫 글자 앞에 `'`, 채택 여부: 예)
- 관련 결정 ID: D38

## 맥락
`report --csv`와 `compare --csv`는 질문, evidence, 정답·예측 SQL을 엑셀에서 열 CSV로 쓴다(0007). 셀이 `=`, `+`, `-`, `@` 등으로 시작하면 엑셀이 글자가 아니라 수식으로 읽는다. 이를 CSV 수식 주입이라고 한다. 모델이 `=HYPERLINK(...)` 같은 값을 내놓거나 예측 SQL이 `-- 주석`으로 시작하면, 엑셀에서 수식이 실행되거나 `#NAME?` 오류가 난다. 2026-11-11에 커밋된 결과로 만든 CSV 3개(각 432행)에는 이런 셀이 없었다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| 그대로 두고 문서에 경고 | CSV가 원본과 똑같음, 다른 도구로 읽어도 값이 그대로임 | 엑셀에서 수식이 실행되거나 오류가 날 수 있음 |
| 위험한 첫 글자 앞에 `'` (OWASP 권고) | 엑셀이 글자로 읽고 `'`는 화면에 안 보임, 해당 셀만 바뀜 | pandas 등으로 읽으면 `'`가 보임, 엑셀에서 저장 후 다시 열면 효과가 사라질 수 있음 |
| 위험한 첫 글자 앞에 탭 (OWASP의 엑셀용 권고) | 엑셀에서 저장 후 다시 열어도 비교적 유지됨 | 보이지 않는 탭이 데이터에 남음 |

## 결정
CSV에 쓰는 모든 셀에서 첫 글자가 아래 문자 중 하나이면 앞에 `'`를 붙인다. `report --csv`와 `compare --csv` 둘 다 적용한다.

- `=`, `+`, `-`, `@`
- 탭, 캐리지 리턴(CR), 줄바꿈(LF)
- 전각 `＝`, `＋`, `－`, `＠`

## 이유
추천안(위험한 첫 글자 앞에 `'`를 붙임)을 채택했다.

보충: 이 CSV는 처음부터 엑셀용(UTF-8 BOM)이고, `'`는 OWASP가 권하는 방법이다. 탭과 달리 바뀐 것을 눈으로 확인할 수 있다.

## 결과
- 이 CSV를 프로그램으로 읽는 사람은 첫 글자가 `'`이고 그다음이 위 문자이면 `'`를 떼어 원래 값을 얻는다. 원본 값이 필요하면 실행 파일(JSON)을 읽는 것이 정확하다.
- 엑셀에서 CSV를 저장한 뒤 다시 열면 보호가 사라질 수 있다(OWASP 경고). 분석 결과는 엑셀 형식(.xlsx)으로 저장하도록 문서에 적는다.
- 처리 규칙과 예는 CSV 형식 문서(11/13 `reference/`)에 적는다.
