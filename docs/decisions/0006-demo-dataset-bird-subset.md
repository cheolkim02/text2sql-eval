# 0006. 시연 데이터는 BIRD dev의 작은 DB 3개(432문제)를 저장소에 포함한다

- 날짜: 2026-11-04 (기록: 2026-11-07)
- 상태: 채택 (계획서 초판의 합성 데이터를 대체)
- 결정자: 사용자
- AI 관여: 선택지 조사·추천, 라이선스와 DB 크기 확인 (Claude 추천: superhero·student_club·toxicology 전체 문제, 채택 여부: 예)
- 관련 결정 ID: D5
- 편집: 2026-11-15, 공개 전에 프로젝트와 무관한 개인 정보를 지움([0047](0047-remove-unrelated-personal-content.md))

## 맥락
사용자는 연구에서 BIRD를 주로 썼다. 시연 데이터는 누구나 바로 돌려 볼 수 있게 저장소에 들어 있어야 하는데, BIRD dev DB는 0.2MB부터 597.8MB까지 크기 차이가 크다. 재배포 가능 여부도 확인해야 했다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| 합성 데이터 30~40문제 (초판) | 사용자의 연구 경험과 연결 | 직접 설계·작성 비용, 공신력 낮음, 문제 수가 적어 통계 검정이 약함 |
| BIRD dev 작은 DB 일부 문제만 | 가벼움 | 문제 수가 적어 비교가 약함 |
| BIRD dev 작은 DB 3개 전체 문제 | 공신력 있는 벤치마크, 432문제로 비교·검정에 충분, 약 5.5MB | CC BY-SA 4.0 표기를 따로 관리해야 함 |

## 결정
BIRD dev(2024-06-27 판)의 `superhero`(0.2MB, 129문제), `student_club`(2.6MB, 158문제), `toxicology`(2.7MB, 145문제) 전체 432문제와 DB 파일을 `examples/bird-mini`에 넣는다.

## 이유
추천안을 채택했다. 데이터를 저장소에 넣어도 되는지 라이선스를 확인한 뒤 DB 3개를 확정했다.

확인한 내용: BIRD 공식 사이트가 데이터 라이선스를 CC BY-SA 4.0으로 바꿨다고 공지했고, 원 논문은 원본 DB가 퍼블릭 도메인·CC-BY·CC-BY-SA 중 하나라고 밝힌다. 큰 DB(`card_games` 261.8MB, `european_football_2` 597.8MB, `codebase_community` 481.4MB)는 저장소에 넣기 어렵다.

## 결과
- `examples/bird-mini/LICENSE`(CC BY-SA 4.0)와 `SOURCE.md`(논문, 사이트, 다운로드 URL, 판 날짜, 고른 DB와 이유)를 둔다.
- 전체 dev가 필요한 사용자를 위해 다운로드 스크립트를 둔다.
- 데이터를 바꾸면 `SOURCE.md`에 남긴다.
