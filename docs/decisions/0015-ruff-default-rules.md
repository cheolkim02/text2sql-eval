# 0015. Ruff는 기본 규칙만 쓰고, 줄 길이는 88자로 한다

- 날짜: 2026-11-07
- 상태: 채택
- 결정자: 사용자
- AI 관여: 선택지 조사·추천 (Claude 추천: 넓게 고른 규칙 세트, 채택 여부: 아니오)
- 관련 결정 ID: D28

## 맥락
Ruff(0011)가 어떤 규칙을 검사할지 정해야 했다. 규칙이 많을수록 품질 증거는 강해지지만, 처음 만드는 사용자가 경고의 의미를 이해하고 대응하는 비용도 커진다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| 기본값 (문법 오류와 명백한 실수: `E4`, `E7`, `E9`, `F`) | 경고가 적고 하나하나 이해할 수 있음 | 품질 증거로는 약함 |
| 넓게 고른 세트 (E, W, F, I, B, UP, SIM, C4, RET, PTH, PT, N, RUF, S, D) | 버그 패턴·스타일까지 잡음 | 경고가 많고 각 규칙의 이유를 설명해야 함 |
| `ALL`에서 일부 끄기 | 가장 엄격 | 이 프로젝트에 맞지 않는 경고가 많음 |

## 결정
Ruff의 기본 규칙 세트를 그대로 쓰고, 줄 길이는 기본값 88자로 둔다. 포맷은 `ruff format`의 기본 설정을 쓴다.

## 이유
> "기본값. 줄 길이는 기본값 88자. 처음 만들어보는 거니까, 품질이 좀 떨어지더라도, 명백한 실수만 잡아보도록 하자."

## 결과
- 품질의 상당 부분은 pyright strict(0013)와 테스트(0014)가 맡는다.
- 규칙을 늘리고 싶어지면, 늘릴 규칙과 이유를 새 ADR로 남기고 한 번에 한 묶음씩 켠다.
