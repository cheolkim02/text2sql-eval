# 0025. CLI는 표준 라이브러리 argparse로 만든다

- 날짜: 2026-11-09
- 상태: 채택
- 결정자: 사용자
- AI 관여: 선택지 조사·추천 (Claude 추천: argparse, 채택 여부: 예)
- 관련 결정 ID: D14

## 맥락
`text2sql-eval eval|report|compare`의 옵션 해석, `--help` 화면, 옵션 오류 메시지를 만들 도구를 정해야 했다. 런타임 의존성은 0개다(0019).

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| argparse (표준 라이브러리) | 의존성 0개, 동작이 투명해 설명하기 쉬움 | 코드가 조금 장황하고 하위 명령 설정을 직접 써야 함 |
| click 8.5.1 (Stable, 의존성 0개) | 데코레이터로 깔끔함, 테스트 도구 제공 | 의존성 1개, 고유한 사용법 |
| typer 0.28.0 (Beta) | 타입 힌트로 옵션 정의 | Beta, 의존성 4개 |

## 결정
argparse로 하위 명령(`eval`, `report`, `compare`)을 만든다.

## 이유
추천안(argparse)을 채택했다.

## 결과
- 런타임 의존성 0개를 유지한다. 첫 런타임 의존성은 SQL 파서(D15)가 된다.
- CLI 진입점은 `pyproject.toml`의 `[project.scripts]`에 등록한다.
- 종료 코드는 계획서의 규약(0 성공, 1 판정 실패, 2 사용법·입력 오류, 3 실행 환경 오류, 130 사용자 중단)을 따른다.
