- 날짜: 2026-11-09
- 상태: 채택
- 결정자: 사용자
- AI 관여: 선택지 조사·추천과 상태 확인 (Claude 추천: gpt-5.4-mini, 채택 여부: 아니오. 사용자가 gpt-4o-mini를 선택했고, Claude가 지원 중단 일정을 알린 뒤 사용자가 다시 확정함)
- 관련 결정 ID: D33

## 맥락
baseline 예측은 저장소의 공개 실측 결과가 된다. 오답이 적으면 사실 추출과 플래그를 보여 줄 재료가 부족하고, 너무 약하면 결과가 의미 없다.

2026-11-09 OpenAI 공식 문서에서 확인한 내용은 다음과 같다.
- gpt-4o-mini는 **Deprecated** 상태다. 기본 스냅샷 `gpt-4o-mini-2024-07-18`의 종료일은 **2027-01-14**이고, 권장 대체 모델은 `gpt-6-luna`다.
- 가격은 1M 토큰당 입력 $0.15, 출력 $0.60이다.
- 추론 모델이 아니다.

## 선택지
| 안 | 가격 (1M 토큰, 입력/출력) | 장점 | 단점 |
| --- | --- | --- | --- |
| gpt-6.1-sol | $2.00 / $10.00 | 가장 정확함 | 오답이 적을 수 있음, 비용 큼 |
| gpt-5.4-mini (Claude 추천) | $0.75 / $4.50 | 현재 세대, 적당한 오답 수 | 추론 토큰 때문에 비용 예측이 어려움 |
| gpt-5-mini | $0.25 / $2.00 | 저렴 | 이전 세대 |
| gpt-4o-mini (사용자 선택) | $0.15 / $0.60 | 가장 쌈(432문제 × 2설정에 약 $0.1), 추론 모델이 아니라 출력이 짧고 안정적, 오답이 충분히 나올 것 | 지원 중단 예정(2027-01-14 종료), 오래된 모델로 보일 수 있음 |
