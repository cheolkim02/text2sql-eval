# 0007. 결과 화면은 정적 HTML 리포트와 CSV로 한다

- 날짜: 2026-11-04 (기록: 2026-11-07)
- 상태: 채택
- 결정자: 사용자
- AI 관여: 선택지 제시 (Claude 추천: 없음, 세 안을 제시)
- 관련 결정 ID: D6

## 맥락
사용자는 오답 분석에서 NL이나 SQL이 길면 읽기 힘들다는 불편을 겪었고, 분석 결과는 엑셀에 정리했다. 결과를 어떤 형태로 보여줄지 정해야 했다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| (a) 터미널 `show` 명령 | 추가 파일 없음 | 긴 SQL·결과 표를 나란히 보기 어려움 |
| (b) 정적 HTML 리포트 (파일 하나, 서버 없음) | SQL 나란히 보기·강조·필터, 오프라인으로 열림 | 템플릿·스타일 작업 필요 |
| (c) CSV 내보내기 | 기존 엑셀 흐름 유지, 사실 열이 미리 채워짐 | 시각적 비교는 약함 |

## 결정
(b) 정적 HTML 리포트와 (c) CSV를 만든다. 터미널에는 요약만 출력한다.

## 이유
(b) 정적 HTML 리포트와 (c) CSV를 골랐다.

## 결과
- HTML은 외부 요청 없이 한 파일로 열린다(구현 방식은 D21).
- CSV는 엑셀에서 한글이 깨지지 않게 UTF-8 BOM으로 쓰고, 빈 `my_category`·`notes` 열을 둔다.
- 케이스 하나를 터미널에 보여주는 `show` 명령은 만들지 않는다.
