# 0016. 문서 언어: README는 한국어와 영어 요약, 코드·커밋·docstring은 영어

- 날짜: 2026-11-07
- 상태: 채택
- 결정자: 사용자
- AI 관여: 선택지 조사·추천 (Claude 추천: README 한국어 + 영어 요약, 코드·커밋·docstring 영어, 채택 여부: 예)
- 관련 결정 ID: D25
- 편집: 2026-11-15, 공개 전에 프로젝트와 무관한 개인 정보를 지움([0047](0047-remove-unrelated-personal-content.md))

## 맥락
1차 독자는 한국어 사용자이고, 도구의 사용자는 국내외 text-to-SQL 연구자다. 11/7까지 계획서·ADR·`SOURCE.md`는 한국어로, 코드·커밋·주석은 영어로 써 왔다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| README 한국어 + 영어 요약 한 단락, 코드·커밋·docstring 영어 | 한국어 독자가 편하게 읽고 해외 연구자도 무엇인지 알 수 있음, 지금까지의 방식과 같음 | 두 언어를 관리해야 함 |
| 전부 영어 | 오픈소스 관례, 사용자층이 넓음 | 작성·설명 부담이 늘고 한국어 독자에게 이점이 적음 |
| 전부 한국어 | 쓰기 편함 | 한국어 코드 주석은 관례에서 벗어나고 해외 사용자가 읽지 못함 |

## 결정
- 한국어: README 본문(맨 위에 영어 요약 한 단락), 가이드·레퍼런스·`architecture.md` 등 `docs/` 아래 문서, ADR, 개발 기록, 계획서
- 영어: 코드 식별자, 주석, docstring, 커밋 메시지, CLI 출력과 오류 메시지
