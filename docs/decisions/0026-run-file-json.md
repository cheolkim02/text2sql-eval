# 0026. 실행 파일은 JSON 파일 하나로 저장한다

- 날짜: 2026-11-09
- 상태: 채택
- 결정자: 사용자
- AI 관여: 선택지 조사·추천과 내용 제안 (Claude 추천: JSON 파일 하나, 채택 여부: 예)
- 관련 결정 ID: D31

## 맥락
`eval`의 결과를 저장할 파일 형식을 정해야 했다. `report`(HTML, CSV)와 `compare`가 이 파일을 읽고, 사용자가 직접 열어 보기도 하는 공개 형식이다. 연구에서 "어떤 설정으로 돌렸는지"를 스크립트 옵션과 Weights & Biases로 찾던 불편을 이 파일이 대신 기록한다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| JSON 파일 하나 | 읽기 쉽고, `report`·`compare`가 한 번에 읽음 | 아주 큰 데이터셋에서는 파일이 커짐 |
| JSONL (첫 줄 요약, 이후 한 줄에 케이스 하나) | 큰 데이터셋에 유리 | 요약과 케이스를 읽는 방식이 달라 번거로움 |
| 파일 두 개 (`summary.json` + `cases.jsonl`) | 요약만 빨리 볼 수 있음 | 두 파일의 짝이 어긋날 수 있음 |

## 결정
JSON 파일 하나에 다음을 담는다.
- **실행 정보:** `schema_version`, 도구 버전, 실행 시각(UTC), 데이터셋·예측 파일·동점 파일의 경로와 SHA-256 해시, 설정(시간 제한, 행 제한, 누락 허용), 사용자 메타데이터
- **요약:** 전체 수, `correct`·`incorrect`·`error` 수, EX
- **케이스별:** id, db_id, 난이도, 판정, 오류(어느 쪽, 종류, 메시지), 플래그, 예측 SQL, 빈 예측·누락 여부, 정답과 예측 결과의 앞부분 20행과 전체 행 수

## 이유
추천안(JSON 파일 하나)을 채택했다.

## 결과
- `compare`는 데이터셋 해시가 다른 두 실행을 비교할 때 경고한다.
- 결과 행은 앞부분 20행만 저장한다. 동점 문제처럼 수백 행이 나오는 경우 파일이 커지지 않게 하기 위해서다.
- JSON으로 그대로 쓸 수 없는 SQLite 값(바이트, 무한대 실수)은 표시 규칙을 정해 문자열로 바꾸고, `docs/reference/run-file.md`에 적는다.
- 형식이 바뀌면 `schema_version`을 올린다.
