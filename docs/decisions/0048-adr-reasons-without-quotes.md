# 0048. ADR의 이유는 대화를 인용하지 않고 평서문으로 쓴다

- 날짜: 2026-11-16
- 상태: 채택
- 결정자: 사용자
- AI 관여: 인용 위치 조사와 규칙 선택지 제시 (Claude 추천: 평서문으로 쓰고 규칙도 바꿈, 채택 여부: 예)
- 관련 결정 ID: D44

## 맥락
0001부터 ADR의 "이유"에는 사용자가 대화에서 한 말을 그대로 인용했다(AGENTS.md 결정 절차). 저장소를 공개한 뒤 보니, 인용에는 "이대로 진행해줘"나 "PR 올려서 merge해줘" 같은 작업 지시가 섞여 있었다. 이 도구를 쓰는 사람에게 필요한 것은 결정의 이유이지 대화 원문이 아니다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| 평서문으로 쓰고 규칙도 바꿈 | 기존 ADR과 새 ADR의 형식이 같음, 대화가 다시 공개되지 않음 | 원문이 아니므로 옮기면서 뜻이 조금 달라질 수 있음 |
| 기존 ADR만 고치고 규칙은 유지 | 바꿀 규칙 파일이 없음, 원문이 남음 | 형식이 섞이고, 새 ADR부터 대화가 다시 공개됨 |
| 평서문으로 쓰되, 쓰기 전에 사용자가 문장을 확인 | 옮긴 문장이 맞는지 사용자가 직접 확인 | 결정할 때마다 단계가 하나 늘어남 |

## 결정
ADR의 "이유"는 사용자의 말을 인용하지 않고 평서문으로 쓴다. 사용자가 밝힌 이유를 담고, 이유 없이 추천을 따랐으면 "추천안(…)을 채택했다"고 쓴다. 기존 ADR 0003~0047의 인용도 이렇게 바꾼다. ADR 밖의 문서는 그대로 둔다.

## 이유
ADR에 적힌 대화 원문은 이 라이브러리를 쓰는 사람이 알 필요 없는 내용이다. 앞으로의 규칙은 추천안(평서문으로 쓰고 규칙도 바꿈)을 채택했다.

## 결과
- 기존 ADR 45개(0003~0047)의 이유를 평서문으로 바꿨다.
  - 인용만 있던 곳에는 채택한 안을 적었다.
  - "보충"은 그대로 두었다.
  - 0042의 보충과 0047의 결과에 있던 인용도 지웠다.
- 규칙을 바꾼 곳은 다음과 같다.
  - `AGENTS.md`의 결정 절차
  - `decide` 스킬
  - ADR 템플릿(`0000-template.md`)
  - `CONTRIBUTING.md`
  - `docs/PLAN.md`의 ADR 템플릿
- 사용자가 남기기로 한 것은 다음과 같다.
  - ADR의 "결정자"·"AI 관여" 줄과 도구를 모른다고 밝힌 보충
  - 개발 기록
  - `docs/ai-workflow.md`의 인용
  - `docs/PLAN.md`
- 옮긴 문장이 사용자의 뜻과 맞는지는 사용자가 PR diff에서 확인한다.
- 이전 커밋에는 인용이 남는다.
