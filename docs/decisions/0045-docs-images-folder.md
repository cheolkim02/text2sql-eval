# 0045. 문서용 이미지는 docs/images/에 둔다

- 날짜: 2026-11-14
- 상태: 채택
- 결정자: 사용자
- AI 관여: 위치 제안 (Claude 제안: `docs/images/`, 채택 여부: 예)
- 관련 결정 ID: D41
- 편집: 2026-11-15, 공개 전에 프로젝트와 무관한 개인 정보를 지움([0047](0047-remove-unrelated-personal-content.md))

## 맥락
README와 가이드에 HTML 리포트 스크린샷을 넣는다. 이미지 파일을 둘 폴더가 저장소에 아직 없다. 폴더 구조는 사용자가 정하는 결정이다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| `docs/images/` | 문서와 함께 있어 상대 경로가 짧고, 문서용 자료라는 것이 드러남 | 폴더가 하나 늘어남 |
| `examples/results/` (리포트 옆) | 실측 결과와 한곳에 모임 | 예제 데이터 폴더에 문서용 파일이 섞임 |
| 저장소 밖(이슈 첨부 등의 외부 URL) | 저장소 크기가 늘지 않음 | 외부에 의존해 링크가 깨질 수 있고, 링크 검사 테스트로 확인할 수 없음 |

## 결정
README와 `docs/` 문서가 쓰는 이미지는 `docs/images/`에 둔다.

## 이유
> "docs/images/ 만들어줘."

## 결과
- 스크린샷은 사람이 볼 이미지이므로 2배 해상도로 찍고, 커밋된 실행 파일로 만든 리포트에서 찍는다.
- 문서의 이미지 링크도 `tests/test_docs.py`의 링크 검사 대상이다.
