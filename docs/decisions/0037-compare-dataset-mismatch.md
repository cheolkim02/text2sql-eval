# 0037. 데이터셋이 다른 두 실행은 경고하고 공통 케이스만 비교한다

- 날짜: 2026-11-11
- 상태: 채택
- 결정자: 사용자
- AI 관여: 선택지 조사·추천 (Claude 추천: 경고 + 공통 케이스 비교, 채택 여부: 예)
- 관련 결정 ID: D36

## 맥락
실행 파일에는 데이터셋 파일의 SHA-256 해시가 있다(0026). 다른 데이터셋으로 돌린 두 실행을 그대로 비교하면 숫자의 의미가 없다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| 해시가 다르면 경고하고 공통 케이스 id만 비교 | 데이터셋이 조금 바뀐 경우도 비교 가능, 숨기지 않음 | 경고를 놓칠 수 있음 |
| 해시가 다르면 오류(종료 코드 2) | 가장 안전함 | 같은 문제인데 파일만 다시 저장한 경우도 막힘 |

## 결정
데이터셋 해시가 다르면 요약 맨 앞에 경고를 출력한다. 두 실행에 모두 있는 케이스 id만 비교하고, 한쪽에만 있는 케이스 수를 함께 보여 준다. 공통 케이스가 하나도 없으면 입력 오류로 처리한다.

## 이유
추천안(경고 + 공통 케이스 비교)을 채택했다.

## 결과
- EX와 분할표는 항상 공통 케이스 기준이다. 실행 파일의 전체 EX와 다를 수 있으므로, 요약에 공통 케이스 수를 적는다.
