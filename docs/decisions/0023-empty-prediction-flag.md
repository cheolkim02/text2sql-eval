# 0023. 빈 예측은 공식과 똑같이 판정하고, 정답 처리되면 플래그를 단다

- 날짜: 2026-11-08
- 상태: 채택
- 결정자: 사용자
- AI 관여: 선택지 조사·추천 (Claude 추천: 공식과 똑같이 판정 + 플래그, 채택 여부: 예)
- 관련 결정 ID: D29

## 맥락
모델이 SQL을 내지 않은 경우를 어떻게 판정할지 정해야 했다. 텍스트 예측 파일의 빈 줄, JSONL에서 누락을 허용해 빠진 케이스가 여기에 해당한다. BIRD 공식 코드는 예측이 없으면 공백 SQL `" "`을 실행하고, 그 결과는 빈 집합이다. 그래서 정답 결과도 빈 집합이면 정답으로 처리된다(거짓 정답). bird-mini에는 정답이 빈 결과인 문제가 없어(0/432) 시연 데이터에서는 점수 차이가 없다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| 공식과 똑같이 실행해서 비교 | 공식 점수와 같음 | 거짓 정답이 조용히 섞임 |
| 빈 예측은 항상 오답 | 가장 정직함 | 정답이 빈 결과인 데이터셋에서 공식 점수와 달라짐 |
| 공식과 똑같이 판정하고, 정답 처리된 빈 예측에 플래그 | 공식 점수와 같으면서 거짓 정답이 드러남 | 플래그를 읽어야 알 수 있음 |

## 결정
빈 예측과 누락된 예측은 빈 SQL로 실행해 공식과 똑같이 판정한다. 그 결과가 정답으로 판정되면 "빈 예측이 정답 처리됨" 플래그를 단다.

## 이유
추천안(공식과 똑같이 판정하고, 정답 처리된 빈 예측에 플래그)을 채택했다.

## 결과
- 누락된 예측(JSONL, 누락 허용)과 빈 예측(빈 줄, `"sql": ""`)은 같은 경로로 처리하되, 실행 파일에는 둘을 구분해 기록한다.
- 이 플래그는 신뢰도 플래그 목록(D19)의 후보가 된다.
