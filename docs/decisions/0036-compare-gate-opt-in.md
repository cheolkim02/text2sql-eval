# 0036. compare는 기본적으로 실패하지 않고, --max-drop을 줄 때만 기준을 적용한다

- 날짜: 2026-11-11
- 상태: 채택
- 결정자: 사용자
- AI 관여: 선택지 조사·추천 (Claude 추천: 기본은 실패 없음, 채택 여부: 예)
- 관련 결정 ID: D35

## 맥락
계획서는 `compare`가 허용 하락폭(`--max-drop`, 기본 0)을 넘으면 종료 코드 1을 내도록 했다. 그런데 이 도구의 주 용도는 로컬에서 실험을 바꿔 가며 비교하는 것이다(0004, 계획서 "구조").

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| 기본은 실패 없음, `--max-drop X`를 줄 때만 기준 적용 | 실험 비교 때 실패 코드가 나오지 않음, CI에서는 옵션으로 켬 | 옵션을 알아야 함 |
| 기본 0 (조금이라도 떨어지면 실패) | 엄격함 | 작은 하락에도 매번 실패, CI 전용 도구처럼 보임 |

## 결정
`compare`는 기본적으로 종료 코드 0이다. `--max-drop X`를 주면, 공통 케이스 기준 EX가 X%p보다 많이 떨어졌을 때 종료 코드 1을 내고 그 이유를 출력한다.

## 이유
> "둘 다 추천대로 구현하고 PR 올려서 merge해줘"
