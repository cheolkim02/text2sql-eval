# 0009. 지원 Python 버전을 3.11 이상으로 한다

- 날짜: 2026-11-07
- 상태: 채택
- 결정자: 사용자
- AI 관여: 선택지 조사·추천 (Claude 추천: 3.11+, 채택 여부: 예)
- 관련 결정 ID: D8

## 맥락
지원 범위의 하한을 정해야 했다. 2026-11-07 기준 Python 3.10은 지원이 끝났고(2026-10-01), 3.11은 2027-10까지 보안 패치를 받으며, 최신은 3.15다.

## 선택지
| 안 | 장점 | 단점 |
| --- | --- | --- |
| 3.11+ | 지원이 살아 있는 버전 중 가장 넓게 포함, 표준 `tomllib` 사용 가능 | 3.12의 새 제네릭 문법(`type` 별칭 등)을 쓸 수 없음 |
| 3.12+ | 새 제네릭 문법으로 타입 코드가 간결함 | 3.11 사용자 제외 |
| 3.13+ | 최신 기능 | 사용자층이 좁아짐 |

## 결정
`requires-python = ">=3.11"`로 하고, CI는 3.11부터 최신까지 테스트한다.

## 이유
> "3.11+. 3.11 사용자 포함시키기 위함."

## 결과
- 3.12 이상 전용 문법(`type` 문, PEP 695 제네릭 문법)은 쓰지 않는다. 제네릭은 `TypeVar`로 쓴다.
- 3.11이 지원 종료되는 2027-10에 하한을 다시 본다.
